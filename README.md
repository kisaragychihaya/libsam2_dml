# libsam2_ncnn

SAM2 (Hiera-Small) inference on **ncnn**, packaged as a C-ABI DLL plus a pure-Go
(no cgo) example client. The encoder and decoder support CPU and Vulkan backends;
ncnn is statically linked, so the native runtime is a single `sam2_ncnn.dll`.

The DLL accepts an RGB24 image and point prompts, runs prompt embedding internally,
and returns low-resolution mask logits and IoU predictions. Returned buffers are
owned by the DLL, handles are serialized with mutexes, and errors are available
through a thread-local ASCII string.

- C ABI usable from other languages; the included Go client uses `syscall`, not cgo
- one native DLL, with ncnn statically linked
- CPU and Vulkan providers, with runtime fallback from Vulkan to Cpu
- deterministic synthetic QC image generated by the Go client
- CI builds CPU/Vulkan variants and checks logits against an independent Python reference

## Model assets

The v0.2.0 release contains five ncnn model files:

| Asset | Purpose |
| --- | --- |
| `sam2_encoder_fixed.ncnn.param` / `.bin` | Image encoder; 1024x1024 RGB input, FPN features and image embedding outputs |
| `sam2_decoder_fixed.ncnn.param` / `.bin` | Dense-input mask decoder; mask logits and IoU outputs |
| `sam2_prompt.bin` | Point embedding tables, frozen positional projection, no-mask prior and image positional encoding |

Pass the encoder and decoder `.param` paths to the C API. Each matching `.bin` must
be next to its `.param`, and `sam2_prompt.bin` must be next to the decoder param.

`example/test_data/sam2_qc_reference.bin` is a 256 KB PyTorch reference for the
deterministic QC image. `example/ref_dump.py` can regenerate it or produce a reference
for another image using the original SAM2 checkpoint.

## C API

The full contract is in [`native/include/sam2_ncnn.h`](native/include/sam2_ncnn.h).

```c
const char*          sam2_get_last_error(void);
void                 sam2_shutdown(void);

sam2_encoder_t*      sam2_encoder_create(const char* model_path_utf8, int device_id);
void                 sam2_encoder_destroy(sam2_encoder_t*);
const char*          sam2_encoder_provider(const sam2_encoder_t*); /* "Vulkan" or "Cpu" */
sam2_embedding_t*    sam2_encoder_encode(sam2_encoder_t*, const unsigned char* rgb,
                                         int width, int height, int stride);
void                 sam2_embedding_destroy(sam2_embedding_t*);

sam2_decoder_t*      sam2_decoder_create(const char* model_path_utf8, int device_id);
void                 sam2_decoder_destroy(sam2_decoder_t*);
const char*          sam2_decoder_provider(const sam2_decoder_t*);

/* labels: 1=positive, 0=negative, 2=box top-left, 3=box bottom-right */
sam2_decode_result_t* sam2_decoder_decode(sam2_decoder_t*, const sam2_embedding_t*,
                                          const float* points_xy, const int32_t* labels,
                                          int32_t n_points);
void                 sam2_decode_result_destroy(sam2_decode_result_t*);
```

```c
typedef struct {
    float*  masks;      /* [num_masks][mask_h][mask_w] float32 logits */
    float*  iou;        /* [num_masks] float32 */
    int32_t num_masks;
    int32_t mask_h;
    int32_t mask_w;
} sam2_decode_result_t;
```

Important FFI details:

- `sam2_decode_result_t` is 32 bytes on x64; the integer fields are at offsets 16, 20 and 24.
  `example/main.go` verifies this layout before calling the DLL.
- Release returned handles with their matching `*_destroy` functions, then call
  `sam2_shutdown()` before process exit. This destroys ncnn's global Vulkan instance
  while the driver is still fully loaded; skipping it can crash NVIDIA drivers during
  DLL unload. The function is idempotent and is a no-op in CPU-only builds.
- Creation performs a warmup inference. Calls on the same handle are thread-safe but serialized.
- Preprocessing is half-pixel bilinear resize to 1024x1024, `/255`, ImageNet normalization
  and NCHW float32 conversion.

## Build on Windows x64

Requirements: Visual Studio 2022 with MSVC v143, CMake 3.20 or newer, Ninja, Git and
Git Bash. `native/build.sh` locates the Visual Studio tools automatically; override
discovery with `VCVARS=`, `CMAKE=` and `NINJA=` when needed.

```bash
./native/build.sh                         # CPU -> native/build/sam2_ncnn.dll
VULKAN=1 ./native/build.sh                # Vulkan (bundled loader and shader compiler)
NCNN_ROOT=/path/to/ncnn-install ./native/build.sh
```

Equivalent CMake commands:

```bat
cmake -S native -B native\build -G Ninja -DCMAKE_BUILD_TYPE=Release -DSAM2_VULKAN=OFF
cmake --build native\build
```

Without `NCNN_ROOT`, CMake fetches ncnn at commit
`0a2c46bc75987a39d3b044c77385c564e83c0a84`, builds it statically and links it into
`sam2_ncnn.dll`. `NCNN_ROOT` can instead point to an existing install prefix containing
`include/` and `lib/`. The model conversion and CI numerical checks were validated with
this ncnn revision; other revisions are not assumed to be compatible.

| `SAM2_VULKAN` | Provider | Requirements |
| --- | --- | --- |
| `OFF` (default) | `Cpu` | No GPU SDK or runtime requirement |
| `ON` | `Vulkan`, or `Cpu` after fallback | Vulkan device for GPU execution; loader and shader compiler are built from ncnn sources |

The Vulkan path uses fp32 storage and arithmetic for numerical stability. If no requested
Vulkan device is available, creation succeeds on Cpu and `sam2_get_last_error()` explains
the fallback.

## Go example

Stage the client, DLL and five model files together:

```text
bin/
  sam2qc.exe
  sam2_ncnn.dll
  sam2_encoder_fixed.ncnn.param
  sam2_encoder_fixed.ncnn.bin
  sam2_decoder_fixed.ncnn.param
  sam2_decoder_fixed.ncnn.bin
  sam2_prompt.bin
```

From the repository root:

```bash
./example/run_qc.sh                     # deterministic synthetic image
./example/run_qc.sh path/to/photo.png   # caller-supplied image
```

The script builds with `CGO_ENABLED=0`, stages the DLL and models, runs inference and,
unless `CROSSCHECK=0`, compares the logits with the Python reference.

| Environment variable | Meaning | Default |
| --- | --- | --- |
| `SAM2_DLL` | Path to `sam2_ncnn.dll` | next to `sam2qc.exe` |
| `SAM2_ENCODER` | Encoder ncnn `.param` | next to the exe, then one/two directories above |
| `SAM2_DECODER` | Decoder ncnn `.param` | same search order |
| `SAM2_MODEL_DIR` | Model directory used by the shell scripts | repository root |
| `SAM2_DEVICE` | Vulkan device index | `0` |
| `SAM2_RUNS` | Timed iterations per stage | `5` |
| `SAM2_EXPECT` | Required provider substring, `Cpu` or `Vulkan` | `Cpu` |
| `SAM2_ALLOW_CPU` | Warn instead of failing when Vulkan falls back to Cpu | unset |
| `SAM2_REF_LOGITS` | Existing PyTorch reference for a custom QC image | checked-in reference for the synthetic image |
| `SAM2_CHECKPOINT` | SAM2 checkpoint used to generate a custom-image reference | `sam2_hiera_small.pt` in the repository root |

The QC executable writes `go_logits.bin`, `go_rgb.bin` and `mask_output.png` in its current
directory. These are local QC outputs, not distribution files.

```bash
sam2qc.exe --gen-test-image example/out/test_image.png
sam2qc.exe example/out/test_image.png
```

Loading the library from Go requires no cgo:

```go
dll := syscall.NewLazyDLL(`C:\path\to\sam2_ncnn.dll`)
create := dll.NewProc("sam2_encoder_create")
p, _ := syscall.BytePtrFromString(`C:\path\to\sam2_encoder_fixed.ncnn.param`)
enc, _, _ := create.Call(uintptr(unsafe.Pointer(p)), 0)
```

## Numerical QC

The default QC compares the exact RGB bytes consumed by the DLL with the checked-in
PyTorch single-mask reference. Maximum absolute logits error must be no greater than
`2e-2`; the current CPU build passes with binary mask IoU 1.0.

For another image, `example/crosscheck.sh` can generate a matching reference with
`example/ref_dump.py`. This optional development step requires PyTorch, SAM2, Pillow,
NumPy and the original `sam2_hiera_small.pt` checkpoint. CI uses the checked-in reference
and only needs NumPy.

Set `SAM2_DEBUG_DUMP` to a directory to make the DLL dump intermediate encoder/decoder
buffers for debugging. These dumps are not needed for normal inference.

## CI and distribution

`.github/workflows/build-and-qc.yml` is manually triggered and has two jobs:

1. `libncnn` builds static ncnn once with `NCNN_VULKAN=ON` at the pinned commit and caches
   the install tree by commit and runner OS/architecture.
2. `build-and-qc` restores that cache, builds and tests the `cpu` and `vulkan` matrix legs,
   and checks both against the Python reference.

The Vulkan-enabled static library serves both matrix legs. The CPU DLL delay-loads the
Vulkan loader, so it does not require Vulkan at runtime. Hosted runners normally have no
Vulkan GPU; the Vulkan leg permits a warned Cpu fallback while keeping the numerical gate.

Each matrix leg uploads only `dist-<version>.zip`, containing `bin/sam2qc.exe` and
`bin/sam2_ncnn.dll`. Models, reference data, images and logs are not included in the zip.
`version` is a workflow input; when empty it defaults to `git describe --tags --always`.
Model files are distributed separately as release assets.

## Platform notes

- The current build helper and pure-Go example target Windows x64. The C++ implementation
  uses ncnn and standard C++17, but other platforms require their own build/client validation.
- Encoder input is fixed at 1024x1024 with the preprocessing recipe described above.
- Use the pinned ncnn revision for the supplied models; numerical failures and decoder
  crashes have been observed with incompatible revisions.
